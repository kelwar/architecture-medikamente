## Задание 1. Анализ безопасности системы

### Элементы данных

- Персональные данные пациентов: ФИО, дата рождения, телефон, электронная почта.
- Расширенные персональные данные пациентов: адрес прописки, место работы/учёбы, хронические заболевания.
- Медицинские карты (приёмы, процедуры, анализы, диагнозы).
- Платежные данные пациентов.
- Персональные данные работников (кроме публичной информации, такой как ФИО, образование и трудовая деятельность медицинских специалистов)
- Данные о взаиморасчетах с работниками.
- Финансовые данные организации.
- Данные о поставщиках услуг (кроме публичной информации о партнёрах).
- Данные о взаиморасчетах с поставщиками.
- Данные о применяемых ТМЦ (кроме публичной информации об оборудовании).

### Процессы

- Пациент записался на приём.
- Пациент прошёл приём.
- Пациент сдал анализы.
- Пациент оплатил приём.
