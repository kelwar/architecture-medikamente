### Проблемные зоны:

1. Разрешения на обработку персональных данных не собираются в явном виде.
2. Персональные данные хранятся в файлах, доступ к файлам ограничен только групповыми доменными политиками.
3. По этой причине любой медицинский специалист имеет доступ к медицинской карте любого пациента клиники, даже того, кто у него никогда не лечился.
4. В системе, в которой нет технической возможности ограничить доступ только необходимостью осуществления деятельности, должны быть введены чёткие регламенты обработки персональных данных всем персоналом организации.
5. Отсутствует отслеживание пациентов, договор с которыми прекращён. Т.е. такие данные хранятся уже в возможных маркетинговых целях, что не соответствует первоначальной цели сбора персональных данных. Для маркетинговой цели оператор должен получить отдельное согласие пациента на обработку персональных данных в целях маркетинга.

### Данные для защиты:

1. ФИО - обфускация (токенизация).
2. Дата рождения - маскирование (динамическая маскировка данных).
3. Электронная почта. - маскирование (динамическая маскировка данных), сокрытие средней части адреса.
4. Телефон - маскирование (динамическая маскировка данных), можно маскировать полностью или частично.
5. Адрес прописки - маскирование (динамическая маскировка данных), полная маскировка, т.к. необходим только для оформления договора/контракта
6. Место работы/учёбы - маскирование (динамическая маскировка данных), для раскрытия при определенных условиях, например при госпитализации.
7. Хронические заболевания - шифрование (т.к. эта информация может потребоваться в процессе лечения).
8. Мед. карта - шифрование.
9. Результаты анализов - шифрование.
10. Данные о взаиморасчетах - шифрование.

### Тэгирование:

1. ФИО - PII
2. Дата рождения - PII
3. Электронная почта. - PII
4. Телефон - PII
5. Адрес прописки - PII
6. Место работы/учёбы - PII
7. Хронические заболевания - PHI
8. Мед. карта - PHI
9. Результаты анализов - PHI
10. Данные о взаиморасчетах - Платежная информация

### Способы и инструменты обеспечения конфиденциальности данных:
1. Обфускация (токенизация).
2. Шифрование.
3. Маскирование (динамическая маскировка данных).
4. Тегирование:
- PII видно всему персоналу, кроме бухгалтерии.
- PHI видно только медицинским специалистам.
- Платежная информация - видна респешен и бухгалтерии.
5. OneTrust - для управления согласиями пациентов.
